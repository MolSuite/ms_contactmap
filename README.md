# ms_contactmap

MolSuite Contact Map: computes protein–ligand contact maps and renders
2D interaction diagrams.

Part of the [MolSuite](https://molsuite.github.io/) stack.

## Install

```bash
pip install git+https://github.com/MolSuite/ms_contactmap
```

## Usage

```bash
ms_contactmap --help
```
